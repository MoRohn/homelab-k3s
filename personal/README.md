# personal/ — your notes (git-ignored)

Everything here except this README stays on this machine: notes, drafts, scratch output,
diagnostics dumps, and exports of AI assistant memory or reasoning you want to keep.

Suggested layout (create as needed):

| Folder | For |
|---|---|
| `notes/` | Running notes and journals |
| `drafts/` | Docs not ready to publish. Move to a tracked folder when ready |
| `archive/` | Retired configs and old credentials-adjacent files |
| `ai/` | Saved assistant memory, transcripts, thinking exports |

Claude Code keeps its own memory and transcripts outside the repo (`~/.claude/projects/…`),
so they can never be committed from here.
