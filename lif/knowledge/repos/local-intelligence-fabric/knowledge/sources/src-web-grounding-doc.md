The conversation, files, images: never leave the box. The built search query (≤ 200 chars) leaves, to SearXNG and then public engines, and the console shows it. ^p1

A query containing a key, email, phone number or card-like number is never sent: the lookup is blocked. A RESTRICTED prompt is never looked up. ^p2

Owner decision 2026-10-03: lookups are allowed under "Local only", because only the query is sent. ^p3
